# Mini Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Next.js + TypeScript mini blog UI with a dashboard, profile page, and blog modal based on the provided Figma.

**Architecture:** Create a route-based App Router app with typed mock data, a shared application shell, focused UI components, and a client-side modal interaction on the dashboard.

**Tech Stack:** Next.js, React, TypeScript, CSS, Testing Library, Vitest
